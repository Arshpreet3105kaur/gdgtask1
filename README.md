# Exploratory Data Analysis (EDA) - Road Accidents Dataset

## 📌 Project Overview
This project performs a comprehensive Exploratory Data Analysis (EDA) on a road accidents dataset comprising **202,000 records and 48 features**. The goal is to uncover hidden patterns, analyze contributing factors, and derive meaningful insights regarding accident severity and traffic dynamics.

---

## 📊 Key Findings & Insights
1. **Dataset Scale:** Analyzed 202,000 rows and 48 columns covering diverse geographical, vehicular, and environmental attributes.
2. **Accident Severity:** The analysis highlights the distribution of accident severities (Minor, Moderate, Severe), showing how various external parameters influence risk levels.
3. **Speed & Dynamics:** Examined correlations between speed limits, estimated speeds, and accident occurrences, identifying major risk thresholds.
4. **Data Hygiene:** Performed initial missing value checks and anomaly detection (such as handling inconsistent negative values in fatality records) to ensure robust data quality.
